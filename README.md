# img-warehouse

二次元随机图图库仓库，按分类整理 PC 横图、移动竖图及原神、初音未来、萌版等专题图片，可作为个人图床 / 随机图接口的静态资源使用。

- 图片格式：WebP 原图（无缩略参数）
- 命名规则：`序号_原站文件名`，序号与图库预览页顺序一致
- 唯一图片总数：约 **3049 张**（`acg` 为 `pc` 的复制，不计入）

## 自适应分类

“自适应”分类由对应横图与竖图组合而成，可根据设备方向自动返回合适的图片：

| 自适应分类 | 构成 |
| :--- | :--- |
| 二次元自适应 | PC 横图 `pc` + 移动竖图 `mp` |
| 萌版自适应 | 萌版横图 `moe` + 萌版竖图 `moemp` |
| 原神自适应 | 原神横图 `ys` + 原神竖图 `ysmp` |
| 初音未来自适应 | 初音未来横图 `miku` + 初音未来竖图 `mikump` |

## 使用方式

将本仓库的图片部署到任意静态托管（如 GitHub Pages、Vercel、对象存储）后，即可自行搭建随机图接口，按分类返回图片。
